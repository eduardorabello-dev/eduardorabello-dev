## Sobre mim

Estudo Análise e Desenvolvimento de Sistemas na Universidade São Francisco (conclusão prevista em 2028) e trabalho como Aprendiz de TI na Elsys, onde lido todos os dias com problemas reais de usuários. Essa vivência me ensinou a entender a dor de quem usa o sistema antes de escrever código.
